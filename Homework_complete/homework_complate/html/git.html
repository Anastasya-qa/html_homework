Git

  • git init - создание нового локального репозитория.
  • git clone - клонирование существующего удалённого репозитория.
  • git status - проверка статуса файлов.
  • git add - добавление файла или всех изменений в индекс.
  • git commit -m - фиксация изменений в истории.
  • git log - просмотр историй коммитов.
  • git branch - список веток или создание новой.
  • git checkout -b - создание новой ветки и переключение на неё.
  • git push - отправка изменений из локального репозитория в удалённый.
  • git pull - получение и слияние изменений из удалённого репозитория.
